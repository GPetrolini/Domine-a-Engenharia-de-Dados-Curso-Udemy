# 🚀 SQL Server - Engenharia de Dados 📊

Este diretório armazena os scripts SQL e materiais de estudo do módulo de **SQL Server**, parte integrante do curso "Domine a Engenharia de Dados". O foco é a aplicação prática do SQL Server no contexto da engenharia de dados.

## 🔎 O que você encontrará aqui:

* **Scripts SQL:** Exemplos práticos, exercícios resolvidos e demonstrações cobrindo diversos aspectos do SQL Server, desde consultas básicas até tópicos mais avançados.
* **Tópicos abordados:**
    * Consultas (`SELECT`, `JOINs`, `GROUP BY`, etc.)
    * Manipulação de Dados (`INSERT`, `UPDATE`, `DELETE`)
    * Criação e Gerenciamento de Objetos de Banco (`CREATE TABLE`, `VIEWS`, `INDEXES`)
    * Stored Procedures e Funções
    * Window Functions
    * Controle de Transações

## 🛠️ Como usar:

1.  **Navegue pelos arquivos `.sql`** para encontrar os exemplos e exercícios.
2.  **Abra os scripts** no SQL Server Management Studio (SSMS), Azure Data Studio ou seu editor SQL de preferência.
3.  **Execute e analise** as queries para entender a lógica e os resultados.
4.  **Adapte e experimente** os códigos em seu próprio ambiente de desenvolvimento SQL Server.

## 🎯 Objetivo:

Consolidar o aprendizado em SQL Server, uma ferramenta crucial para engenheiros de dados na modelagem, extração, transformação e carregamento de dados (ETL), além da análise e otimização de performance de bancos de dados.
